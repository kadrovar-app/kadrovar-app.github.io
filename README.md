# KadroVar

Kamu alım ilanları (KPSS'li, KPSS'siz, kamu işçi) ve KPSS tercih robotu. Uygulama: https://kadrovar-app.github.io/

- iPhone/iPad: Safari'de aç → Paylaş → Ana Ekrana Ekle.
- Android: Chrome'da aç → Yükle (ya da ⋮ → Uygulamayı yükle).

İlanlar resmî kaynaklardan (Resmî Gazete, Kariyer Kapısı, MSB, ÖSYM, İŞKUR) kontrol edilerek `data/ilanlar.json` dosyasında güncellenir; yüklü uygulamalar yeni veriyi ve yeni sürümü kendiliğinden alır.
